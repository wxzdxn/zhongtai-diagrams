## 使用方式

- 每张图都是**自包含单文件 HTML**，双击即可在浏览器打开，无需联网、无需任何依赖。
- `?theme=light` / `?theme=dark` 指定初始主题（图内右下角也可切换）。
- `?embed=1` 隐藏页头，便于嵌入其他文档或看板。
- `?present=1` 进入演示模式。
- 图内元素支持**动画追踪**，可按路径逐段播放，适合汇报演示。

`src/` 保留了每张图的源 JSON，修改后可用 Archify 重新渲染：

```bash

```

## 三个尚未封闭的口径风险

1. **母本绑定率 ≥80%** 把 `ref_text` 计入绑定 —— 把 444 条自由文本搬进新字段指标立刻达标，但一个母本都没结构化。建议拆三档：结构化绑定率 ≥30% / 文本保留率 ≥95% / 待补录绝对数。
2. **上线 ID 与开机时间填充率** 未排除未上线 / 未开机状态时，分母被稀释，指标虚高。
3. **迁移一致率 ≥95%** 的分子分母与抽样方式均未定义。建议定死三条线：抽样 ≥10%、字段级准确率 ≥98%、挂起率 ≤5%，任一不达线不放行。
